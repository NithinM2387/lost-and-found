# Lost and Found System

## About
This is a web application for reporting and finding lost and found items.
Users can report items, browse reports, search items, and check possible matches.

## Features
- User signup and login
- Report lost and found items
- Browse and search approved items
- Filter items by type and category
- View item details and possible matches
- Update your own item status
- View profile and previous reports
- Admin can approve, reject, and remove reports

## Technologies
- Frontend: React, Vite, React Router, CSS
- Backend: Node.js, Express
- Database: MongoDB with Mongoose
